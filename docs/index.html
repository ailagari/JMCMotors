Drive inputs (click to press)

CW / CCW / SW are the limit and origin switch inputs. FLT raises a drive fault (over-current). PWR power-cycles the drive: it goes offline, then comes back at position 0.

Grammar

One rule for every command

CMD:<slots>

Individual motors. Positional slots: field N = motor N, an empty field skips that motor, a single value with no comma = motor 1. P:1000,,3000 moves M1 and M3.

CMD:M3=500,M17=1000

Motor names instead of counting commas: M3=500 for a value, M3 for a selector or a read. Any order. The practical form past a dozen motors.

CMDA[:value]

All motors: the A suffix. One value (or ?) applies to every motor. PA:5000, VA:0.5, BA, LA, HOA:?.

? reads

In any value slot: P:? (M1), P:,,? (M3), V:M3, HO:?, VA:? (all).

Options in the head

Stop type and homing method are the digit in the head: B2:1,,1, H3A. The status format follows a second colon: S:M1:COMPACT, SA:FLAGS.

The one exception

A bare head is an error (ERR:L needs motor slots…) — except B, B1, B2, B3, which always stop every motor. A stop is never refused.

What the controller sends on its own

A background monitor reads one motor's status every 8 ms and pushes a datagram to PC_IP:PC_PORT on every change — one when a condition appears, one when it clears. Latency ≈ motor count × 13 ms.

Setup

From a bare Controllino to a moving axis

Six steps. The hardware guide has the full wiring, drive-parameter and commissioning detail.

Install

Arduino IDE → Tools → Manage Libraries → JMCMotors. Also install the CONTROLLINO board package. Or add the repository ZIP.

Wire RS-485

A/B daisy-chain from the Controllino's RS-485 port through every drive, 120 Ω across A/B at the last drive, common ground. Limit and origin switches go to the drive's inputs.

Set the drives

On each drive's panel: P43 = 0 (Modbus, the factory default is CANopen), P40 = slave ID 1, 2, 3…, P41 = 7 (115200), P42 sensor polarity, P17 steps per revolution, P19 = 7 for geared loads. Restart the drive.

Configure the sketch

Open JMCMotors_6Motor, edit the three "EDIT ME" blocks: network addresses, MOTOR_COUNT, speeds/ramps/homing (global or a per-motor table). Flash.

Connect

Any UDP tool to CONTROLLINO_IP:CONTROLLINO_PORT. Replies come back to the sender and to PC_IP:PC_PORT; events only go to PC_IP:PC_PORT. Boot sends Motor ready.

Commission

VER → IA → PR:4000 (one turn?) → V:1 + VS:M1 for 60 s (exactly 60 revs?) → ACC/DEC until smooth → Z or H3 → press each switch, watch for EVENT:LIMIT.

In depth

Settings policy, recipes, migration

How settings work: sketch first, SAVE for deployed units

1. The admin configures the sketch

Network, motor count, speeds, ramps and homing live in the "EDIT ME" blocks of JMCMotors_6Motor. Flash once. They are re-applied on every boot and whenever a drive comes back online.

2. Runtime changes, kept without a cable

V, ACC, DEC, HV, HVZ, HACC, HO, MC last until reboot — unless the operator sends SAVE, which stores them in EEPROM. SAVE:? shows what is stored, SAVE:CLEAR forgets it, LOAD re-applies it.

3. The sketch always wins after a re-flash

The saved block carries a fingerprint of the sketch values it was made under and is ignored as soon as the admin flashes different ones. An old SAVE can never override a new flash.
